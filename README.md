# Nasa-Sans
### Another APOD fetching website but in sans :)
Alright so had a lot of fun building this one, also my last project for stardance too! :)    
Fetches the APOD image of the day by NASA!

## NOTE-
Currently the NASA APOD API is facing some backend problems due to which all information is being reverted back to the original boilerplate nasa logo and description!  
Check the documentation [HERE](https://github.com/nasa/apod-api/issues/184).


## LOCAL SETUP-
+ Open the repository you want to clone the folder in and click "Open in Terminal" in the folder.
+ Run `git clone https://github.com/Mk1A-Falcon/Nasa-Sans.git`
+ Run `npm install`
+ Run `npm run dev`  
A dev server would be opened at 
http://localhost:5174/Nasa-Sans/
